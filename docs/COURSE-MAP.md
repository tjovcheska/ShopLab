# Course map

Which parts of ShopLab support each module of the Playwright course. Paths are relative to `http://localhost:3000`. Locators for every page are in [LOCATORS.md](LOCATORS.md), and slow or flaky behaviour is in [CHAOS.md](CHAOS.md).

Seeded accounts: `alice@shoplab.test` / `Password123!` (customer with 2 orders), `bob@shoplab.test` / `Password123!` (customer), and `admin@shoplab.test` / `Admin123!`.

## Modules

| Module                         | Pages and endpoints                                                                                                                                                                                                                                                     | What students practice                                                                                                                                                                                                                                |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **POM Introduction**           | `/login`, `/register`, `/products`, `/products/[slug]`, `/cart`, `/checkout`                                                                                                                                                                                            | One page object per page. The header (search, cart count, log in/out) is a shared component used by every page object. Checkout is a natural place for one object per wizard step.                                                                    |
| **Timeouts**                   | `?delay=<ms>` on any page, the `shoplab_delay` cookie, `/chaos`, `CHAOS_DELAY_MS`; affected widgets: `/products` grid, `/products/all`, search suggestions, live stock, new arrivals                                                                                    | Default `expect`, action, and test timeouts, and per-assertion, per-group, and per-project overrides. See CHAOS.md exercise 1.                                                                                                                        |
| **Playwright Configuration**   | Docker `shoplab` (3000) and `shoplab-staging` (3001, 500 ms delay); `GET /api/test/health`, `POST /api/test/reset`, `POST /api/test/users`, `POST /api/test/products`, `POST /api/test/login-as` (with `TEST_HOOKS_ENABLED=true`)                                       | Projects per environment with different `baseURL`s; `webServer` waiting on `/api/test/health`; global setup that resets the database and saves `storageState` through `/api/test/login-as`.                                                           |
| **Advanced Locators**          | `/playground/table` (duplicate rows), `/playground/shadow-dom`, product cards on `/` and `/products`, `/login` ("Log in" used four times), `/register` ("Password" vs "Confirm password"), `/admin` and `/api-docs` (no test IDs)                                       | `getByRole` with names, `exact`, `filter({ hasText, has })`, chaining, `nth`, scoping into shadow DOM; why `getByRole('alert')` needs scoping (LOCATORS.md, Gotchas).                                                                                 |
| **Dynamic Elements & Waits**   | Header search autocomplete (300 ms debounce), toasts (3 s), `/products/all` infinite scroll, home "New arrivals" (random 1–3 s), live stock on `/products/[slug]` (every 5 s), loading skeletons on `/products?delay=2000`                                              | Web-first assertions instead of sleeps; `toBeVisible`/`toBeHidden`; `waitForResponse`; `expect.poll` for the live stock value.                                                                                                                        |
| **Complex UI**                 | `/checkout` wizard (custom region dropdown, custom date picker, native country select, radios), `/cart` (steppers, confirmation modal), `/playground/drag-drop`, `/playground/upload`, `/playground/hover`, `/products` (range sliders, switch, multi-checkbox filters) | `selectOption` vs clicking a custom listbox, keyboard navigation, `dragTo`, `setInputFiles`, `hover`, `fill` on range inputs, handling disabled dates.                                                                                                |
| **Multiple Pages & Frames**    | Payment iframe in `/checkout` (`/embed/payment`), `/playground/frames` (nested + sibling frames), the "Share" popup and "Size guide" new tab on `/products/[slug]`, `/playground/dialogs`                                                                               | `frameLocator`/`contentFrame`, nested frames, `waitForEvent('popup')` vs `context.waitForEvent('page')`, acting in a popup and asserting on its opener, `page.on('dialog')`.                                                                          |
| **Cross-Browser / Multi-tab**  | All `/playground/*` pages (checked in Chromium, Firefox, and WebKit), the "Size guide" tab and "Share" popup                                                                                                                                                            | Projects for `chromium`, `firefox`, `webkit`; real browser differences (for example, `dialog.accept()` on a prompt keeps the default only in Firefox); several tabs in one context.                                                                   |
| **Error Handling & Stability** | `shoplab_flaky` cookie and `/chaos` (flaky mode), "Try again" on `/products` and `/products/all`, `/playground/visibility` (hidden, removed, disabled, covered, off-screen)                                                                                             | Asserting error states deterministically, retries and their risks, `toPass`, reading "element intercepts pointer events" errors, visible vs attached vs enabled. See CHAOS.md exercises 4–5.                                                          |
| **Test Data Management**       | Deterministic seed (`npm run db:seed`, `POST /api/test/reset`), `POST /api/test/users`, `POST /api/test/products`, `POST /api/test/login-as`, REST API for carts and orders                                                                                             | Creating isolated data per test, resetting between runs, fixtures that create a user, logging in through the API instead of the UI, keeping test data independent.                                                                                    |
| **Reporting & Logging**        | Any failing scenario: declined card `4000 0000 0000 0002` in the payment iframe, flaky mode, wrong password on `/login`, out-of-stock add to cart                                                                                                                       | Traces, screenshots and videos on failure, `test.info().attach()`, `test.step()` names, the HTML report, annotating known issues.                                                                                                                     |
| **API Automation**             | `/api/v1/*` (17 operations), `/api-docs`, `/api/v1/openapi.json`                                                                                                                                                                                                        | The `request` fixture, bearer token vs cookie auth, status codes 200/201/204/400/401/403/404/409/500, schema checks against the OpenAPI document, combining API setup with UI checks (an order created through the API appears on `/account/orders`). |
| **CI/CD**                      | `Dockerfile`, `docker-compose.yml`, `GET /api/test/health`, `docs/ci-example.yml`, `smoke/`                                                                                                                                                                             | Starting the app in a container, waiting for health, running tests against both environments, sharding, uploading reports as artifacts.                                                                                                               |

## Every page at a glance

| Path                          | What it is                                                                                      | Login                   |
| ----------------------------- | ----------------------------------------------------------------------------------------------- | ----------------------- |
| `/`                           | Home: categories, top-rated products, "New arrivals" (random delay)                             | —                       |
| `/products`                   | Catalog with filters, sort, and pagination in the URL; loads through the API                    | —                       |
| `/products/all`               | Infinite scroll                                                                                 | —                       |
| `/products/[slug]`            | Product detail: quantity, add to cart, live stock, reviews, size guide (new tab), share (popup) | add to cart needs login |
| `/search?q=`                  | Search results                                                                                  | —                       |
| `/size-guide`                 | Size tables (opened in a new tab)                                                               | —                       |
| `/popup/share`                | Share window (opened with `window.open`)                                                        | —                       |
| `/login`, `/register`         | Authentication forms                                                                            | —                       |
| `/account`, `/account/orders` | Profile and order history                                                                       | customer                |
| `/admin`                      | Admin dashboard (403 for customers)                                                             | admin                   |
| `/cart`                       | Cart with steppers and remove confirmation                                                      | customer                |
| `/checkout`                   | 4-step wizard; payment in an iframe                                                             | customer                |
| `/orders/[id]`                | Order confirmation and detail                                                                   | owner or admin          |
| `/chaos`                      | Instructor panel for delay and flaky mode                                                       | —                       |
| `/playground`                 | Index of the practice pages below                                                               | —                       |
| `/playground/frames`          | Nested and sibling iframes                                                                      | —                       |
| `/playground/dialogs`         | Native alert, confirm, and prompt                                                               | —                       |
| `/playground/drag-drop`       | Sortable list and two-column board                                                              | —                       |
| `/playground/shadow-dom`      | `<shoplab-rating>` Web Component                                                                | —                       |
| `/playground/upload`          | File upload (single and multiple) and CSV download                                              | —                       |
| `/playground/table`           | Sortable, filterable table with row checkboxes                                                  | —                       |
| `/playground/hover`           | Hover-only menus, tooltips, and buttons                                                         | —                       |
| `/playground/visibility`      | Hidden, removed, disabled, covered, and off-screen elements                                     | —                       |
| `/api-docs`                   | REST API documentation                                                                          | —                       |
